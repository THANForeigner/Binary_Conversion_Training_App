## Features
This training application provides a focused environment to practice challenging binary representations:

* **Fixed-Point Conversion (16-bit):** Train on converting **decimal numbers** to:
    * One's Complement
    * Two's Complement
    * Bias (Excess) Notation
* **Floating-Point Conversion (32-bit):** Practice converting **decimal floating-point numbers** to the standard **IEEE 754** binary representation.

## Getting Started
Follow these instructions to get the application up and running on your local machine.

### Prerequisites
This application requires **Python** and its dependencies.

1.  Ensure you have **Python 3.9** installed.
2.  Install the required libraries using the provided **`requirements.txt`** file.
### Installation
1.  **[Clone the repository](https://github.com/THANForeigner/Binary_Conversion_Training_App)** (if hosted on Git) or download the project files.
2.  Open your terminal or command prompt in the project's root directory.
3.  Install the necessary dependencies:

    ```bash
    pip install -r requirements.txt
    ```
### Usage
Run the main application file from your terminal or an integrated development environment (IDE):
```bash
python number_systems_game.py
```
